# ⚡ OmniCompiler AI

> An intelligent code compiler, real-time line error locator, and educational refactoring engine built with **React 19, Tailwind CSS, Vite, and Node.js**.

---

## ✨ Key Features

- **⚡ Multi-Language Execution**: Run Python, JavaScript, C++, Java, and SQL.
- **🎯 Exact Line Error Pinpointing**: Pinpoints error lines in red with root-cause explanations.
- **✅ Right Solution Engine**: Side-by-side / line-by-line diffs with 1-click **"Apply Fix to Editor"**.
- **📚 Programming Topics Extractor**: Auto-detects data structures & algorithms (Loops, Arrays, Async/Await, Pointers, SQL Aggregations).
- **🔀 Alternate Solution & Trade-offs**: Provides alternative algorithmic solutions with Pros, Cons, and Time & Space Complexity bounds.
- **⏱️ Big-O Complexity Gauge**: Compares Time & Space complexity before and after fixing bugs.
- **🔬 Visual Debugger**: Step-by-step line execution visualizer with live stack variable state tracking.
- **🤖 AI Refactoring Assistant**: Built-in chatbot for unit tests, bug explanations, and interview tips.
- **📱 Responsive UI**: 100% responsive design across smartphones, tablets, laptops, and desktop screens.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS v4, Vite, Lucide Icons, Canvas Confetti
- **Backend**: Node.js HTTP/API Engine

---

## 🚀 Quick Start

```bash
# 1. Clone repository
git clone https://github.com/linusydv/omnicompiler-ai.git

# 2. Install dependencies
npm install

# 3. Start development server
npm run dev

# 4. (Optional) Start Node.js API server
npm run server
```
